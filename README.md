# 🚨 Disaster Alert Web Application

A simple and responsive **web application** that provides disaster alert information using frontend technologies.

The project is designed to demonstrate **HTML structure**, **CSS styling**, and **JavaScript-based interactivity**.

---

## 🔗 Live Demo
👉 https://disaster-alert-blue.vercel.app/

---

## ✨ Features
- Displays disaster alert information
- Clean and responsive user interface
- Lightweight and fast
- Works on modern web browsers

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---------|--------|
| HTML | Structure of the application |
| CSS | Styling and layout |
| JavaScript | Dynamic behavior and logic |
